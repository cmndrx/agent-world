What you're looking at

Each house is a project folder. Each Sim is a Claude Code or Codex session working in it. A Sim with a laptop is a helper (sub-agent) that its agent started.

Bubbles, screens and the diamond above each head are real: they show what the agent is doing right now, with the actual files and commands. A yellow diamond means it needs you.

Coffee breaks and couch time are just for fun while an agent is idle.
